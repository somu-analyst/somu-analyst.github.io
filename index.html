Job Search Copilot

Finds the right jobs, writes an honest resume for each one, coaches the interview and tracks every application from the inbox.

  • Finds jobs from 40+ sources and scores each one against the person's resume.
  • Tailors truthfully: RAG matches every requirement to real experience, and a check blocks any claim the resume can't back up.
  • Interview coach: quizzes, mock video interviews and AI feedback on a recorded answer.
  • Tracks itself: reads employer replies in Gmail and moves each application forward.
  • For staffing firms: one job pool with a profile per consultant.

WallStreet Agentic TradeOps

An options-intelligence terminal that turns market data into explained trade signals, and scores its own predictions every day.

  • Open-interest flow, dealer gamma and a 24-model signal ensemble, with Black–Scholes and Monte Carlo pricing.
  • Each model is weighted by its recent hit rate; walk-forward checks catch signals that only fit noise.
  • An LLM gateway that fails over across providers, and an MCP server that gives AI agents read-only access.
